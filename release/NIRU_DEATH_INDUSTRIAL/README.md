# NIRU DEATH INDUSTRIAL

**32 dark atmospheric tones for the Roland GAIA 2**

Created by **Nicklas Rudolfsson** · 2026

An early sound bank created for my own music and shared freely for use in yours.
Future updates may refine or expand the collection.

> **Hardware testing pending:** the files have been structurally checked in
> software, but have not yet been imported or auditioned on a physical GAIA 2.
> The descriptions below are design intentions, not listening-test results.

## Install

1. Back up any user tones you wish to keep: importing overwrites selected slots.
2. Copy `NIRU_DEATH_INDUSTRIAL.svz` to `ROLAND/SOUND` on a GAIA 2-formatted or
   compatible FAT32 USB drive.
3. Connect the drive and choose **MENU → File → Import** on the GAIA 2.
4. Select the bank, mark the tones and destination slots, and confirm.

The `patches/` directory contains the same tones as individual `.svz` files.
